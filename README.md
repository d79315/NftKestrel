# NftKestrel

Provides customizable, web-based dashboards for tracking and analyzing NFT market trends and portfolio performance.

NftKestrel is built to be simple and practical, focusing on doing one thing well.

**Why NftKestrel?**

- Provides customizable, web-based dashboards for
- tracking and analyzing NFT market
- trends and portfolio performance

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/NftKestrel.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
